# Documentation

- `policies/` contains the contributor and engineering policies referenced by
  the root `AGENTS.md`.
- `adr/` records architecture decisions.
- `ENFORCEMENT-MANIFEST.md` is generated from the active enforcement configuration.
- `STARTING-A-PROJECT.md` covers initialization, runtime setup, and repository settings.
- `features/` and `design/` contain the starter's reusable acceptance and design examples.

Keep documentation about the current system here. Session reports, command logs,
screenshots, and failure transcripts belong in pull requests or CI artifacts.
Local run output belongs in ignored `.artifacts/`.
